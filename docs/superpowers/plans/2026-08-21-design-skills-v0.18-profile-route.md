# Design Skills v0.18 Profile Route Roadmap

## Goal

Complete the Thread → Profile identity path with a shareable Mina Park profile that makes contribution history, saved context, circles, and trust signals reviewable on web and mobile.

## Scope

- [x] Open Profile from the account identity controls.
- [x] Preserve the profile identity in a shareable URL.
- [x] Render Profile identity, contribution stats, circles, conversations, and saved context.
- [x] Add Conversations/Saved tabs with selected state and polite status feedback.
- [x] Add follow/unfollow pressed state and accessible feedback.
- [x] Route Profile conversation cards back into the existing Thread route.
- [x] Capture Profile at desktop and mobile sizes.
- [x] Add a dedicated Profile visual regression baseline.
- [ ] Replace local profile state with authenticated account and saved-data integration when backend scope exists.
- [ ] Add native Profile implementations and simulator evidence for iOS and Android.

## Review note

The static responsive web surface remains review-ready, not release-ready: Profile now demonstrates identity and contribution context, while authentication, persistence, native runtime, and deployment evidence remain integration work.
