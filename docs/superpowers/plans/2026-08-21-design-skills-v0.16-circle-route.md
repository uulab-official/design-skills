# Design Skills v0.16 Circle Route Roadmap

## Goal

Complete the first meaningful community journey after Discover by making Circle / City Makers a real, shareable detail route with the interaction states described on the design board.

## Scope

- [x] Open a Circle detail route from a Discover card.
- [x] Preserve the Circle name in a shareable URL.
- [x] Expose Your circles as the current destination in desktop and mobile navigation.
- [x] Reset scroll on Circle entry and restore Discover through browser back.
- [x] Translate the board’s Circle identity into a responsive hero, orbit artwork, conversation list, and context rail.
- [x] Add Conversations and About tabs with selected state and polite status feedback.
- [x] Add join/leave pressed state and route-boundary feedback for conversation actions.
- [x] Capture Circle at desktop and mobile sizes.
- [x] Add a dedicated Circle visual regression baseline.
- [ ] Replace conversation route-boundary feedback with a persisted Thread route when reply data and backend scope are available.

## Review note

The responsive web surface remains review-ready, not release-ready: Circle now demonstrates a production-shaped community detail flow, while native runtime, backend persistence, authentication, and deployment evidence remain scope-dependent.
